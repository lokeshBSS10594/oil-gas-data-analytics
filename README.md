# Oil & Gas Production & Operations Analytics

## Project Overview

This project presents an end-to-end data analytics solution for analyzing
oil and gas production, operational performance, equipment status,
downtime, costs, and revenue.

The project covers the complete analytics workflow from raw data ingestion
and SQL-based data storage to Python-based data cleaning and exploratory
analysis, followed by an interactive Power BI dashboard.

## Business Objectives

- Analyze oil and gas production trends
- Identify high-performing fields and regions
- Monitor production efficiency
- Analyze downtime and operational performance
- Evaluate water cut across fields
- Analyze operating and maintenance costs
- Understand revenue contribution
- Monitor equipment and production status

## Dataset

The dataset contains approximately 15,000+ production records with
information related to:

- Well
- Field
- Region
- Well Type
- Production Date
- Oil Production
- Gas Production
- Water Cut
- Operating Hours
- Downtime
- Maintenance Cost
- Operating Cost
- Revenue

- Production Status

## Data Cleaning

The dataset was cleaned using Python and Pandas.

Key cleaning activities included:

- Duplicate record removal
- Missing value treatment
- Invalid water-cut value handling
- Invalid operating-hour handling
- Negative production value validation
- Cost and revenue validation
- Data type standardization

## Power BI Dashboard

The dashboard contains six primary KPIs:

1. Total Oil Production
2. Total Gas Production
3. Total Revenue
4. Production Efficiency
5. Average Water Cut
6. Total Downtime Hours

Additional analysis includes:

- Monthly production trends
- Oil production by field
- Revenue by region
- Production status
- Equipment status
- Field performance
- Revenue vs operating costs
- Maintenance cost analysis
